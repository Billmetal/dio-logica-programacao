# 🦸 Classificador de Nível de Herói

## 📋 Descrição

Este projeto é um desafio de lógica de programação que classifica heróis de acordo com sua experiência (XP). O sistema recebe o nome e a quantidade de XP de um herói e determina seu nível de poder através de uma estrutura de decisão.

## 🎯 Objetivo

Criar um classificador que utilize variáveis, operadores, laços de repetição e estruturas de decisão para categorizar heróis em diferentes níveis baseados em sua experiência acumulada.

## 🏆 Níveis de Classificação

O herói é classificado de acordo com a seguinte tabela de XP:

| XP                    | Nível        |
|-----------------------|--------------|
| Menor que 1.000       | Ferro        |
| 1.001 até 2.000       | Bronze       |
| 2.001 até 5.000       | Prata        |
| 5.001 até 7.000       | Ouro         |
| 7.001 até 8.000       | Platina      |
| 8.001 até 9.000       | Ascendente   |
| 9.001 até 10.000      | Imortal      |
| 10.001 ou mais        | Radiante     |

## 💻 Tecnologias Utilizadas

- JavaScript

## 🚀 Como Executar

1. Clone o repositório
2. Execute o arquivo JavaScript usando Node.js:
```bash
node classificador-heroi.js
```

Ou copie o código e execute diretamente no console do navegador (F12).

## 📤 Saída Esperada

O programa exibe uma mensagem no formato:
```
O Herói de nome **[nome]** está no nível de **[nível]**
```

## 📝 Exemplo

```javascript
let nomeHeroi = "Thor";
let xpHeroi = 7500;

// Saída: O Herói de nome Thor está no nível de Platina
```
